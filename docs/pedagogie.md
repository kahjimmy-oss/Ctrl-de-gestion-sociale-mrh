# Stratégie Pédagogique & Game Design

## 🎓 Philosophie Pédagogique

**Objectif global** : Transformer la **compréhension passive** en **expertise active** via une approche constructiviste et socioconstructiviste adaptée au Master.

### Principes
1. **Apprentissage par problème** (PBL) - Missions complexes, ambiguës, réalistes
2. **Variation des réponses** - Pas de réponse unique ; débat, réflexion critique
3. **Validation progressive** - Débloquer contenu = preuve de compréhension
4. **Peer learning** - Missions collectives + débriefing collectif
5. **Individualisation** - Évaluation perso + progression personnalisée
6. **Métacognition** - Réfléchir sur sa réflexion (rapports d'analyse)

---

## 🎮 Mécanique Gamifiée

### Progression Non-Linéaire
```
┌─ Séance 1 : Audit RH ─────────────────┐
│  Question préalable (variation)       │
│          ↓ (correcte)                 │
│  Mission 1 débloquée                  │
│  Équipe: Créer tableau de bord        │
│  Indiv: Éval 20/20                    │
│          ↓ (réussi)                   │
│  Accès Séance 2                       │
└───────────────────────────────────────┘
```

### Points & Badges (Optionnel)
- ✅ Réponse correcte = +10 points
- ✅ Soumission excellent = +25 points
- ✅ Participation collective = badge "Team Builder"
- ✅ Analyse profonde = badge "Expert Analyst"

### Feedback Multi-Niveaux
1. **Immédiat** (question) : Micro-feedback (2-3 lignes)
2. **Court terme** (mission) : Retour formateur (48h)
3. **Long terme** (séance) : Rapport d'analyse détaillé + score

## 📋 Structure des Missions (4 Séances)

### SÉANCE 1 : Audit Recrutement & Indicateurs RH (3,5h)

**Question Préalable (5 min)**
```
Variation 1 : "Le recrutement est un coût pur pour l'entreprise"
→ Vrai
→ Faux (CORRECT)
→ Partiellement vrai selon contexte

Feedback correct : "Le recrutement est un investissement en capital humain.
À COSMETICA, coûtage moyen recrutement : 3 mois salaire.
Mais impact positif si bon fit culturel et productivité +20%"

Débloque → Accès scénario COSMETICA
```

**Mission Collectif (2h)**
- **Contexte** : COSMETICA recrute 5 salariés cette année. Le taux de démission
  après 6 mois est de 40%.
- **Livrables** :
  1. Audit des 3 derniers recrutements (Données fictives + analyse)
  2. Tableau de bord : indicateurs recrutement (délai moyen, coût/recrutement, etc.)
  3. Plan d'action : améliorations
  
- **Données Fournies** : Profils salariés, contrats, périodes d'intégration
- **Validation** : Prof valide chaque livrable avant progression

**Évaluation Individuel (30 min - 20/20)**
```
Q1 (4/20) : Définir "turnover" et "délai moyen recrutement" (définition + formule)
Q2 (5/20) : Analyse critique : 40% turnover, est-ce acceptable pour cosmétique ? Justifier.
Q3 (6/20) : Proposer 3 indicateurs pour prédire démission future
Q4 (5/20) : Lien budget RH ↔ recrutement. Calculer coût % masse salariale.
```

---

### SÉANCE 2 : Budget RH & Masse Salariale (3,5h)

**Question Préalable (5 min)**
```
Variation 1 : "Adapter la masse salariale à l'activité signifie réduire les salaires"
→ Vrai
→ Faux (CORRECT)
→ Cela dépend du contrat de travail

Feedback : "L'adaptation peut se faire via :
- Variation heures (CDD, temps partiel)
- Primes de performance
- Restructuration (PSE, mobilité interne)
Pas forcément baisse salaire."

Débloque → Données budgétaires COSMETICA
```

**Mission Collectif (2h)**
- **Contexte** : COSMETICA a baisse activité -15% l'an dernier. Budget RH doit s'adapter.
- **Livrables** :
  1. Analyse budget RH : masse salariale, cotisations, formation, recrutement
  2. Projection masse salariale Y+1 selon 3 scénarios (optimiste, réaliste, pessimiste)
  3. Proposition PSE ou mesures alternatives (réduction heures, mobilité)
  4. Calcul impact paie / trésorerie
  
- **Données** : Compte résultat, masse salariale actuelle, contrats salariés

**Évaluation Individuel (30 min - 20/20)**
```
Q1 (4/20) : Calculer taux de charge patronale + taux cotisations URSSAF
Q2 (5/20) : Masse salariale COSMETICA = ? (calcul sur données fournies)
Q3 (6/20) : PSE : définir, contexte légal, impacts RH (turnover, ambiance)
Q4 (5/20) : Analyse critique scénario proposé par équipe. Lequel choisiriez-vous ? Pourquoi ?
```

---

### SÉANCE 3 : Performance, Turnover & Indicateurs Collectifs (3,5h)

**Question Préalable (5 min)**
```
Variation 1 : "Un turnover élevé = mauvaise gestion RH obligatoirement"
→ Vrai
→ Faux (CORRECT - dépend contexte)
→ C'est un indicateur neutre

Feedback : "Dans startup growth mode ou en chimie pharma, turnover 20% normal.
Mais à COSMETICA PME stable, 40% = problème."

Débloque → Données performance
```

**Mission Collectif (2h)**
- **Contexte** : Turnover élevé. Besoin d'analyser performances, absentéisme, productivité.
- **Livrables** :
  1. Analyse turnover : qui part (profils), quand, vers où ?
  2. Analyse absentéisme : taux, motifs, coût estimé
  3. Analyse productivité : output/salaire, évolution, impact mobilité
  4. Corrélation absence ↔ productivité ↔ turnover (existe-t-il ?)
  5. Plan d'action RH : rétention, performance, engagement
  
- **Données** : Fiches individuelles salariés, heures travaillées, AT/MP, CP

**Évaluation Individuel (30 min - 20/20)**
```
Q1 (4/20) : Formule taux turnover, taux absentéisme, productivité (output/h)
Q2 (5/20) : Cas Salarié X : absent 20j/an, productivité basse. Diagnostic RH ?
Q3 (6/20) : Proposer baromètre social : 5 indicateurs clés pour COSMETICA
Q4 (5/20) : Actions correctives : lister 3 actions prioritaires + coût estimé
```

---

### SÉANCE 4 : Baromètre Social, Reporting & Synthèse (3,5h)

**Question Préalable (5 min)**
```
Variation 1 : "Le baromètre social mesure uniquement la satisfaction"
→ Vrai
→ Faux (CORRECT)
→ Il mesure capital humain : engagement, performance, risques

Feedback : "Baromètre = vue 360° : données + perception + prédicteurs risques"

Débloque → Template rapport final
```

**Mission Collectif (2h)**
- **Contexte** : Synthèse année. Présentation comité direction COSMETICA.
- **Livrables** :
  1. Baromètre social COSMETICA : 10 indicateurs synthétisés (score 0-100)
  2. Rapport contrôle de gestion RH : contexte, analyses, écarts, actions
  3. Tableau de bord exécutif : 1 page executive summary
  4. Présentation orale : 15 min (tout groupe)
  5. Propositions stratégiques Y+1
  
- **Format** : PowerPoint + Fichier Excel dashboards

**Évaluation Individuel (30 min - 20/20)**
```
Q1 (4/20) : Qu'est-ce qu'un "reporting RH efficace" ? Critères ?
Q2 (5/20) : Analyser écarts budgétaires Y vs réalité (données fournies) → actions ?
Q3 (6/20) : Vous êtes DRH. Quel est le TOP 3 des risques sociaux à COSMETICA ?
Q4 (5/20) : Synthèse réflexive : apprentissages, compétences acquises, questions ouvertes.
```

## ❓ Stratégie des Questions

### Variation de Réponses = Déblocage Progressif

**Type 1 : Compréhension (Facile)**
```
Q: "Le taux de turnover se calcule : ?"
A1: (Départs / Effectif moyen) × 100 [CORRECT]
A2: (Départs / Effectif début année) × 100 [Incorrect - mauvaise base]
A3: (Départs / Recrues) × 100 [Incorrect - non pertinent]

→ Correction immédiate + explication
```

**Type 2 : Analyse (Intermédiaire)**
```
Q: "COSMETICA turnover 40%, industrie moyenne 15%.
Quelles peuvent être les causes ? (2-3 propositions + justification)"

A1: Salaires non compétitifs [CORRECT - justifier par données]
A2: Culture d'entreprise [CORRECT - justifier]
A3: Manque formation [CORRECT - justifier]
A4: "Je ne sais pas" [Accepté - orienté vers ressources]

→ Débat collectif sur les hypothèses
```

**Type 3 : Réflexion Critique (Expert)**
```
Q: "Votre plan d'action propose augmentation 10% masses salaires
vs amélioration conditions travail (télétravail, flexibilité, formation).
Quel mix ? Budgets limités. Argumentez."

→ Pas de réponse "correcte" : évaluation sur qualité argumentaire, data-driven
→ Déblocage = démonstration de réflexion stratégique
```

## 📊 Système de Scoring & Validation

### Validation Formateur (Workflow)
```
Étudiante dépose → Email alerté → Dashboard "À traiter"
        ↓
Formateur lit, annote
        ↓
         ├─ Approuve → "Excellent, points +25"
         ├─ Approuve partiellement → "Bon début, revoir point X, puis resoumis"
         └─ Rejette → "À retravailler : manque Y, Z"
        ↓
Étudiante notifiée → Peut progresser ou reprendre
```

### Évaluation Individuelle (20/20)
- **Critères** :
  - Compréhension théorique (40%)
  - Analyse critique (40%)
  - Clarté exposition (20%)

- **Répartition** :
  - 4/20 : Définitions + formules
  - 5/20 : Calculs + applications cas
  - 6/20 : Analyse critique + synthèse
  - 5/20 : Proposition solutions + justification

## 📈 Différenciation Pédagogique

### Pour apprenantes avancées
- Questions bonus "Expert" avec variations complexes
- Missions "Go further" : analyse d'articles RH, benchmarking externe
- Rôle facilitatrice lors débriefing collectif

### Pour apprenantes en difficulté
- Ressources supplémentaires vidéo (3 min max)
- Questions "guidées" : décomposition en sous-questions
- Tutorat par pair (mentorat apprenante avancée)

## 🎨 Immersion Narrative

**COSMETICA™** : PME cosmétique 50-80 salariés, marché concurrentiel
- **Salariés fictifs** : 15-20 fiches détaillées (nom, profil, histoire RH)
- **Événements** : démission, recrutement, conflit, innovation
- **Données** : payroll réaliste, turnover, absence authentique

Cela crée **engagement émotionnel** nécessaire pour apprentissage deep learning.
